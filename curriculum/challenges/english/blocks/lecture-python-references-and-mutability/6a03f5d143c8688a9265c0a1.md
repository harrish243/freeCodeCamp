# --description--

In Python, understanding how variables are stored in memory is critical for writing bug-free code. 

A variable in Python isn't a "bucket" that holds data; it is a **reference** (or pointer) to an object stored in memory. When you write `a = 10`, Python creates an integer object with the value `10` in memory, and makes the variable `a` refer to that object.

When you define a function, the function parameters act as **new local references** to the objects passed into them. 

```py
def add_five(val):
    val = val + 5
    return val

my_num = 10
result = add_five(my_num)
```

In the example above, `my_num` is a reference to the integer `10`. When `add_five(my_num)` is called, the parameter `val` becomes a *new* reference pointing to the *same* `10` object. 

However, when `val = val + 5` executes, it calculates `15`, creates a *new* integer object `15` in memory, and re-assigns the local reference `val` to point to `15`. The original `my_num` reference outside the function remains completely unchanged, still pointing to `10`. 

This localized existence of variables inside functions is known as **scope**.
