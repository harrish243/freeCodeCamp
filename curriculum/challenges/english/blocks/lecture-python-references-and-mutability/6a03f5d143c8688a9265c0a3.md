# --description--

When working with complex data structures like a list of lists, understanding the difference between assignment, shallow copies, and deep copies becomes crucial.

**Assignment (`c1 = a`)**: 
This does not copy anything. It simply creates a new reference `c1` that points to the exact same object `a` points to. All underlying values are shared.

**Shallow Copy (`c2 = copy.copy(a)` or `c2 = a[:]`)**: 
This creates a *new* outer list, but populates it with references to the *same* child objects as the original. If you mutate a nested list inside `c2`, it will also mutate the nested list inside `a`.

**Deep Copy (`c3 = copy.deepcopy(a)`)**: 
This creates a completely independent clone. It recursively copies the outer list and all nested objects inside it. Mutating `c3` will never affect `a`.

```py
import copy

a = [[1, 2], [3, 4]]
c1 = a
c2 = copy.copy(a)
c3 = copy.deepcopy(a)

a.append([5, 6])
a[0].append(99)

print(c1) # Sees both changes: [[1, 2, 99], [3, 4], [5, 6]]
print(c2) # Sees only the inner change: [[1, 2, 99], [3, 4]]
print(c3) # Sees no changes: [[1, 2], [3, 4]]
```

Tools like `memory_graph` can visualize these nested references, helping you see exactly which pointers are shared across shallow copies versus completely isolated in deep copies.
